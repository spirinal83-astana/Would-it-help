Prototype v0.1 — «От тревоги — к ясности»

Откройте index.html в современном браузере. Для теста на телефоне удобнее разместить папку на любом статическом web-хостинге.

Прототип не отправляет данные на сервер. Согласие и до 300 технических событий сохраняются только локально в localStorage браузера. Текстовые ответы пользователя отсутствуют.
